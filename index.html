Deployment Error

Your browser cannot run index.tsx directly. GitHub Pages and Netlify require your code to be "built" (compiled to JavaScript) before they can display it.

How to fix:

  1. Ensure you are using a build tool like Vite.
  2. Run npm run build locally.
  3. Upload the contents of the dist/ folder to GitHub, not the source files.
